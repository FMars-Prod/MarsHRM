# **App Name**: GeoHRM

## Core Features:

- Geolocation Attendance: Real-time, timer-based attendance with GPS verification against pre-approved locations. Includes handling mislocations and break management.
- Admin Override: CEO/Admin can manually edit attendance times with a mandatory reason field for adjustments.
- Leave Request Management: System for staff to submit leave requests that follow a hierarchical approval process (Member -> Team Lead -> HR).
- Reporting/Issue Submission: Staff can log non-emergency issues; admin/HR can view, assign, and update the status.
- Hierarchical Roles & Permissions: Defines user roles (Member, Team Lead, HR Manager, CEO/Admin) with role-based permissions and access controls.
- Data Export: Export attendance and employee data to spreadsheets for external analysis and reporting.
- Announcement Board/News Feed: A dedicated, centralized communication channel for company-wide news, holidays, and policy changes.
- Birthday/Anniversary Alerts: Automated notification/widget to display upcoming work anniversaries and birthdays to boost employee morale.
- HR Compliance & Policy Acknowledgment: A system to distribute company policies (e.g., HR Manual, IT Policy) and require employees to digitally read and acknowledge them, creating an auditable compliance trail.
- Audit Logs: A mandatory feature for security and compliance, tracking every action taken by every user, especially critical operations like changing salary details, editing attendance, or granting high-level access.

## Style Guidelines:

- Primary color: Deep blue (#34495E) to convey professionalism and reliability.
- Background color: Light gray (#F0F3F4) for a clean and neutral interface.
- Accent color: Teal (#008080) for interactive elements and highlights.
- Body text: 'Inter' (sans-serif) for clear readability and a modern look.
- Headline text: 'Space Grotesk' (sans-serif) for a bold and contemporary feel.
- Use clean, minimalist icons to represent attendance, leave, and reporting functions.
- Maintain a clean and organized layout with clear visual hierarchy to ensure easy navigation.
- Subtle transitions and animations to enhance user experience and provide feedback on interactions.
